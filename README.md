# Books for Your Pocket

## Objetivo

Ser uma plataforma brasileira de descoberta e recomendação de ofertas de livros, quadrinhos e mangás.

## Tecnologias planejadas

- **Front-end:** Next.js, React, TypeScript e CSS Modules
- **Back-end:** Python, FastAPI, Poetry, SQLAlchemy 2.0, PostgreSQL, Alembic e Pydantic
